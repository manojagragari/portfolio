# MediConnect24-7 Supporting Document

## Overview
MediConnect24-7 is a full-featured Android healthcare application built with Android Studio.

## Included Support Assets
- Cover: `cover.svg`
- Support placeholders: `support-01.svg` to `support-08.svg`

## Core Features
- Secure patient and doctor login
- Appointment booking and cancellation
- Live consultations
- Medical records management
- Push notifications
- Emergency access
- Doctor and patient dashboards
